### 1. **Val Acc (标准准确率)**

**计算原理**：Top-1准确率，即预测结果完全正确的比例

**代码实现**：
```python
# 计算相似度矩阵
similarity = torch.matmul(image_features, text_features.T)
# 取最大相似度对应的索引作为预测结果
predictions = torch.argmax(similarity, dim=1)
# 真实标签是0,1,2,3...（每个图像对应相同索引的文本）
labels = torch.arange(len(images), device=self.device)
# 统计预测正确的数量
correct_predictions += (predictions == labels).sum().item()

# 最终准确率
accuracy = correct_predictions / total_predictions
```

**数学公式**：
```
Val Acc = (预测完全正确的样本数) / (总样本数)
```

**举例说明**：
- 假设有4个样本，预测结果：[0, 1, 2, 3]，真实标签：[0, 1, 2, 3]
- 完全正确：4个，总样本：4个
- Val Acc = 4/4 = 1.0 (100%)

### 2. **Val Top-5 Acc (Top-5准确率)**

**计算原理**：预测结果在前5个候选中的比例

**代码实现**：
```python
# 获取前5个最高相似度的索引
_, top5_predictions = torch.topk(similarity, k=min(5, similarity.size(1)), dim=1)
# 检查真实标签是否在前5个预测中
top5_matches = (top5_predictions == labels.unsqueeze(1)).any(dim=1)
# 统计Top-5正确的数量
self.top5_correct += top5_matches.sum().item()

# 最终Top-5准确率
top5_accuracy = self.top5_correct / self.top5_total
```

**数学公式**：
```
Val Top-5 Acc = (真实标签在前5个预测中的样本数) / (总样本数)
```

**举例说明**：
- 假设有4个样本，每个样本的Top-5预测：
  - 样本0: [2, 0, 1, 3, 4] → 真实标签0在第2位 ✓
  - 样本1: [1, 3, 2, 0, 4] → 真实标签1在第1位 ✓
  - 样本2: [3, 4, 1, 0, 2] → 真实标签2在第5位 ✓
  - 样本3: [0, 1, 2, 4, 3] → 真实标签3在第5位 ✓
- Top-5正确：4个，总样本：4个
- Val Top-5 Acc = 4/4 = 1.0 (100%)

### 3. **Val R@1 (Recall@1)**

**计算原理**：标准的信息检索指标，正确答案排在第1位的比例

**代码实现**：
```python
# 计算全局相似度矩阵（所有验证样本）
similarity_matrix = torch.matmul(image_features, text_features.T)
n_samples = similarity_matrix.size(0)

# 图像→文本检索 R@1
for i in range(n_samples):
    scores = similarity_matrix[i]  # 第i个图像与所有文本的相似度
    sorted_indices = torch.argsort(scores, descending=True)  # 降序排序
    rank = (sorted_indices == i).nonzero(as_tuple=True)[0].item() + 1  # 找到第i个文本的排名
    i2t_ranks.append(rank)

# 文本→图像检索 R@1  
for i in range(n_samples):
    scores = similarity_matrix[:, i]  # 所有图像与第i个文本的相似度
    sorted_indices = torch.argsort(scores, descending=True)  # 降序排序
    rank = (sorted_indices == i).nonzero(as_tuple=True)[0].item() + 1  # 找到第i个图像的排名
    t2i_ranks.append(rank)

# 计算R@1
i2t_r1 = sum(1 for rank in i2t_ranks if rank <= 1) / len(i2t_ranks)
t2i_r1 = sum(1 for rank in t2i_ranks if rank <= 1) / len(t2i_ranks)
val_r1 = (i2t_r1 + t2i_r1) / 2  # 双向平均
```

**数学公式**：
```
Val R@1 = (I2T_R@1 + T2I_R@1) / 2

其中：
I2T_R@1 = (图像→文本检索中排名≤1的样本数) / (总样本数)
T2I_R@1 = (文本→图像检索中排名≤1的样本数) / (总样本数)
```

**举例说明**：
- 假设有4个样本，全局相似度矩阵：
  ```
  [[0.9, 0.3, 0.2, 0.1],  # 图像0与所有文本的相似度
   [0.2, 0.8, 0.1, 0.3],  # 图像1与所有文本的相似度  
   [0.1, 0.2, 0.9, 0.2],  # 图像2与所有文本的相似度
   [0.3, 0.1, 0.2, 0.8]]  # 图像3与所有文本的相似度
  ```
- 图像→文本检索排名：
  - 图像0: [0, 1, 2, 3] → 文本0排第1位 ✓
  - 图像1: [1, 0, 3, 2] → 文本1排第1位 ✓
  - 图像2: [2, 0, 1, 3] → 文本2排第1位 ✓
  - 图像3: [3, 0, 1, 2] → 文本3排第1位 ✓
- I2T_R@1 = 4/4 = 1.0
- 同理T2I_R@1 = 4/4 = 1.0
- Val R@1 = (1.0 + 1.0) / 2 = 1.0 (100%)

###  **三种指标的区别与联系**

| 指标 | 计算范围 | 评估角度 | 适用场景 |
|------|----------|----------|----------|
| **Val Acc** | 单个batch内 | 分类准确率 | 训练过程监控 |
| **Val Top-5 Acc** | 单个batch内 | 候选命中率 | 细粒度识别评估 |
| **Val R@1** | 全局验证集 | 检索性能 | 模型检索能力评估 |

### **关键差异**：

1. **计算范围**：
   - Val Acc & Top-5 Acc：基于单个batch内的预测
   - Val R@1：基于整个验证集的全局排序

2. **评估标准**：
   - Val Acc：要求完全正确匹配
   - Top-5 Acc：允许在前5个候选中找到
   - Val R@1：要求排在第1位

3. **实际意义**：
   - Val Acc：反映模型的分类准确性
   - Top-5 Acc：反映模型的候选筛选能力
   - Val R@1：反映模型的检索排序能力
