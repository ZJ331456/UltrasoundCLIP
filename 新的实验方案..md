## 实验计划总览

| 实验版本                                                        | 改动内容                                                                                                                                                                        | 所需资源 / 标注需求                                                     | 预期改善方向                                                                                   | 要评估的指标                                                                                                                                              |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Baseline**                                                | 你现在的模型，不带 mask 分支 supervision，只用 mask 可选加权 + cross-attention + global/local 融合                                                                                              | 已有代码 &数据                                                        | 用来做对照的基线                                                                                 | 分类／匹配任务性能（Accuracy / AUC /Top-k if是对比学习／召回） + attention map/pooling 对 mask 区域响应情况（可视化／定量 if mask有） + 推理速度／资源消耗                                      |
| **版本 1：添加 attention side-head + mask loss**                 | 在 `encode_image` 中加一个 attention 输出分支（例如 conv → sigmoid 输出 heatmap），使用真实 mask 对其监督（BCE + Dice 等）。融合 struct\_features 时用这个 attention map 对 struct\_features weighted pooling。 | 需要标注 mask 的样本；算多了损失；资源稍增但不大                                     | 让 attention 更集中于病变／mask 区域，应提升分类精度 +模型对局部细节敏感性；mask-to-attention对齐好则 interpretability 提高 | 分类 /匹配 task性能提升（AUC,Accuracy等）；Heatmap 与 mask 的 IoU /Dice／覆盖率 / attention\_inside\_ratio等；推理时间减少或保持；注意 overfitting 情况（mask supervision过强可能损GENERAL） |
| **版本 2：加入 gating 融合 local vs global 权重**                    | 在版本1基础上，加一个 gate 模块（MLP + Sigmoid）让模型自己学 local\_summary vs global\_summary 的融合权重 w；融合使用 `w * local + (1−w)*global`（或者和 cross-attention fusion结合）                            | 同样 mask 标注样本；增加少量参数；稍微增加训练复杂度                                   | 在不同样本中自适应给 local or global 注重度更灵活，应对各种 lesion 大小／背景噪声情况更好；可能提升在边缘情况的性能                   | 同上 + **融合权重分布** 的统计：看 w 在不同情况如何变化（例如 lesion 小 vs大，噪声强 vs弱），是否合乎预期；是否稳定训练；是否有过拟合（gate 权重极端化）                                                         |
| **版本 3：局部 patch 或多尺度 local branch**                         | 抽若干局部 patch(s) 或滑窗 patches（部分从 lesion／mask 区域，部分随机 background），对这些 patch 特征分别编码 +与 struct/global 融合。可共享 encoder 或部分层。                                                       | 需要额外 patch 生成逻辑，也可能要标注更多局部信息；训练时间增加；内存可能上升                      | 提高对细节（边界、形态、纹理等）的捕捉能力；改善小 lesion 或低对比度区域的表现                                              | 除了基础指标 + attention/heatmap 对 mask 的覆盖情况，还看 patch 分支对这些样本的具体表现（尤其 small lesion 的 recall/precision）；看训练 &推理耗时／资源开销；是否 overfitting 到这些 patch 样本        |
| **版本 4：加入稀疏注意力 / entropy 正则化 + attention supervision loss** | 在版本 1／2 基础上，加一个正则项鼓励 attention map 或 cross-attention 权重不分散（例如熵最小化或 L1 稀疏性），再加监督 attention inside mask vs outside mask 的对比 loss（如果 mask 可用）                                  | 需要 mask；超参数调节较多；训练可能不稳定初期；小心不要让 attention collapse（只看一点就行但忽略其它） | attention map 更集中、更 interpretable；可能减少对背景噪声的误响应；提升总体分类鲁棒性                                | 除基础指标外，额外看 attention maps的 entropy / spacial spread metrics；看 mask coverage；是否分类／matching loss /召回下降（如果过度稀疏）                                        |


## 衡量指标（具体 +定量可用指标）

为了科学比较每个版本，除了常规分类／matching accuracy／AUC等，还建议量化 attention / local 对 mask 区域的对齐性及融合行为。下面是具体指标建议：

| 指标类别                        | 指标                                                 | 说明 /如何算                                                                                |
| --------------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **主任务性能**                   | Accuracy / Precision / Recall / F1                 | 分类任务或 CLIP 相似度任务中区分正确率、召回、精准率等                                                         |
|                             | AUC / ROC / PRC                                    | 特别是二分类任务或不平衡情况                                                                         |
|                             | Top-k /Recall\@k /对比检索精度（如果是匹配任务）                  |                                                                                        |
| **局部关注 /attention map 对齐性** | IoU /Dice /覆盖率 (attention map 与真实 mask 区域 overlap) | 将 attention side-head 或 attention map 二值化（某阈值）看与 mask 的 overlap                        |
|                             | “attention\_inside\_ratio”                         | 所有 attention 权重中，有多少集中在 mask 区域 vs 除外；例如 sum(att\_weights \* mask) / sum(att\_weights) |
|                             | Spatial entropy /spread\*\*                        | 衡量 attention map 是分散还是集中（如 normalize 图像上 attention map，然后算其 entropy 或 variance）        |
| **资源 /部署相关**                | 推理时间 /帧率 /batch推理耗时                                | 看加上 attention分支 + gating +patch 分支后在推理时是否有额外开销（应该设计为可以在推理时关闭某些 branch 或只保留主干）          |
|                             | 模型参数量 /显存使用 /内存峰值                                  |                                                                                        |
| **鲁棒性 /generalization**     | 对于图像中噪声强／对比度低／lesion 小的子集性能                        | 验证集或hold-out集中特别小、小对比度或噪声多的图像，看版本间差距                                                   |
|                             | 稳定性：不同随机 seed /不同训练集 split 下的性能波动                  |                                                                                        |

* **Joint localization and classification of breast tumors on ultrasound images using a novel auxiliary attention-based framework** — 分类 + localization branch +semi-supervised或不完整标注情况下也能用 attention 融合改进性能。 ([arXiv][3])
